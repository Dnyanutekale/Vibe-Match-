## 🌟 Overview

**VibeMate** is a production-style, mobile-first dating and social discovery platform built with **React**, **TypeScript**, and **Tailwind CSS**. Designed with an original glassmorphism UI, neon gradients, and fluid micro-interactions, VibeMate reimagines how modern singles connect through **24-hour ephemeral stories**, **real-time AI wingman assistance**, **interactive card swiping**, and **safety-first dating tools**.

---

## 🚀 Key Features

### 1. 🔥 Interactive Discovery Deck & Match Engine
- **Gesture Swiping**: Swipe right (Like), swipe left (Pass), swipe up (Super Like), or use intuitive touch controls.
- **Match Celebration**: Instant celebratory confetti, dual glowing avatars, and pre-generated AI icebreakers.
- **Advanced Filters**: Age range, distance radius, verified-only badge filter, and Date Mode status.
- **Rich Profiles**: Spotify anthems, astrological signs, career, education, daily prompts, and subculture passions.

### 2. 💬 Real-Time Chat & "Vibe AI" Assistant
- **Vibe AI Reply Generator**: 5 distinct reply vibes (*Flirty & Charming*, *Funny & Witty*, *Deep & Curious*, *Casual & Chill*, *Short & Punchy*). AI never sends without user review.
- **Voice Messages**: Realistic voice note recording simulation with animated acoustic waveforms.
- **Disappearing Messages**: Ephemeral timers (`10s`, `1m`, `1h`, `24h`, or `off`).
- **Date Invitations**: Send interactive date cards directly inside message threads.
- **Rich Reactions**: Pin messages, delete, react with emojis, and share photos.

### 3. ⏱️ 24-Hour Ephemeral Stories
- **Story Viewer**: 5-second auto progress bars, hold-to-pause, interactive poll voting with real-time percentage recalculation, emoji reactions, and direct chat replies.
- **Story Creator**: Snap photo simulator, gradient backdrop chooser, custom overlay text, music tags, and interactive polls.

### 4. 🤖 Vibe AI Wingman Hub
- **AI Profile Analyzer**: 0-100% profile score, photo hook analysis, bio charisma scoring, and one-click bio optimization.
- **AI Date Planner**: City, budget (`$` to `$$$$`), and vibe theme filter (*Coffee & Chill*, *Art & Culture*, *Active Bouldering*, *Natural Wine*) with icebreakers and duration estimations.
- **AI Dating Coach Chat**: Interactive advice chat for date ideas, first date nerves, and conversation starters.

### 5. 🛡️ Safety Center & Privacy Controls
- **Date Check-In Timer**: Automated safety check-in timer that alerts trusted emergency contacts if unconfirmed.
- **Share Date Details**: Encrypted location and match profile snippet sharing.
- **Photo Pose Verification**: Selfie pose verification granting the official Verified Shield badge.
- **Privacy Controls**: Incognito mode, distance masking, read receipts toggle, and online status privacy.

### 6. 🌟 Unique Social Innovations
- **Vibe Check**: Set daily mood (*Creative & Spontaneous*, *Electric Energy*, *Chill & Cozy*, *Romantic Foodie*).
- **Date Mode ⚡**: Spontaneous radar signaling availability for activities today.
- **Shared Playlist**: Collaborative match mixtape with playable audio tracks.
- **Compatibility Quiz**: Fun questions calculating match archetype alignment.
- **Memory Lane**: Private scrapbook documenting milestone connections.
- **Nearby Events Radar**: Discovery of local singles mixers, DJ nights, and bouldering meetups.
- **Admin Dashboard**: Real-time platform metrics, active stories, and live moderation queue.
- **Premium Paywall (Demo)**: Gold & Platinum tiers unlocking boosts, rewinds, and unlimited likes.

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / yarn / pnpm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Dnyanutekale/Vibe-Match-.git

# 2. Navigate to project folder
cd Vibe-Match-

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be running at `http://localhost:5173/`.

### Production Build

```bash
npm run build
npm run preview
```
